# Pantallas Moodify

## Dashboard

Objetivo:
Mostrar indicadores generales del catálogo musical.

Información mostrada:
- Cantidad total de canciones.
- Valencia emocional promedio.
- Energía promedio.
- Popularidad promedio.
- Popularidad por género.
- Distribución emocional.
- Loudness promedio por género.
- Canciones recientes.

Acciones:
- Buscar canciones.
- Agregar canciones.
- Navegar a otras secciones.
